# Pith

Pith is a free, open-source macOS menu-bar app that answers one question at a glance:
"what is using my Mac right now?" A calm dot sits in the menu bar. A click opens one
small panel with a one-line status sentence, three tiles (Memory, CPU, Storage) and the
apps that use the most, with each app's helper processes grouped into one row. It is
built to be extremely light, accurate and native, for Apple Silicon Macs on macOS 15 or
later.

Status: in development.
