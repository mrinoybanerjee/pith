# Stats v3.0.22 teardown: what to borrow for a lighter Mac activity monitor

Date: 2026-10-25. Source: `exelban/stats` tag `v3.0.22` (commit `1282cd52d5bc3b40ca631069e348f8a2c1c8aad9`, 2026-10-18), MIT. Method: shallow clone into a scratch folder, code read only. Nothing was built, run, installed or measured. The clone was deleted after the read.

Labels: **[src]** = read in source at v3.0.22. **[inf]** = my inference from source, not run or measured. **[prior]** = from the 2026-10-24 notes (`build_feasibility.md`, `ux_accuracy.md`), not re-checked here.

All links use `https://github.com/exelban/stats/blob/v3.0.22/PATH#Lx-Ly`.

## Corrections and additions to the 2026-10-24 notes

New findings that matter for the design:
- Default intervals in the settings UI do not match the reader: Disk shows 10 s, reader runs 1 s; Sensors shows 3 s, reader runs 1 s. The reader falls back to `defaultInterval = 1` when the key was never saved ([reader.swift L57, L107-L111](https://github.com/exelban/stats/blob/v3.0.22/Kit/module/reader.swift#L107-L111) vs [Disk/settings.swift L38, L65](https://github.com/exelban/stats/blob/v3.0.22/Modules/Disk/settings.swift#L38), [Sensors/settings.swift L16](https://github.com/exelban/stats/blob/v3.0.22/Modules/Sensors/settings.swift#L16)). [src][inf]
- The Network reader calls `SCDynamicStoreCopyValue` (IPC to `configd`) on every read of `interfaceID`, including once per `getifaddrs` entry, every second ([Net/readers.swift L113-L128, L352](https://github.com/exelban/stats/blob/v3.0.22/Modules/Net/readers.swift#L113-L128)). [src][inf]
- Stats pings `1.1.1.1` (ICMP) every second by default, and fetches the public IP from `api.mac-stats.com` with `curl` at start and on each network change ([Net/readers.swift L966-L968, L1054-L1057, L669-L702](https://github.com/exelban/stats/blob/v3.0.22/Modules/Net/readers.swift#L669-L702)). [src]
- Default update mode is "silent": check at launch, then download and install without asking ([Stats/helpers.swift L135-L152, L178-L205](https://github.com/exelban/stats/blob/v3.0.22/Stats/helpers.swift#L135-L152)). [src]
- macOS 26 gotcha: every layout pass on a status-bar window triggers a WindowServer tiling sync and log spam; Stats patches a private `NSStatusBarWindow` method at launch ([Stats/helpers.swift L385-L404](https://github.com/exelban/stats/blob/v3.0.22/Stats/helpers.swift#L385-L404)). Lesson: keep the status item width fixed and redraw rarely. [src]

## Architecture map

### Component flow (bullet diagram)

- **App process** (`LSUIElement`, not sandboxed, `disable-library-validation` entitlement; [Stats.entitlements](https://github.com/exelban/stats/blob/v3.0.22/Stats/Supporting%20Files/Stats.entitlements))
  - `AppDelegate` builds **all 10 modules at load time**, enabled or not: CPU, GPU, RAM, Disk, Sensors, Network, Battery, Bluetooth, Clock, Remote ([AppDelegate.swift L26-L37](https://github.com/exelban/stats/blob/v3.0.22/Stats/AppDelegate.swift#L26-L37)). Each module is its own framework target (17 Xcode targets in total).
    - **Module** (`Kit/module/module.swift`): reads `config.plist`, makes a `MenuBar`, a Settings `Window`, a `PopupWindow`, plus popup / settings / portal / notifications / preview views ([module.swift L113-L172](https://github.com/exelban/stats/blob/v3.0.22/Kit/module/module.swift#L113-L172)).
      - **Readers** (`Reader<T>`, one per metric) → each owns a **`Repeater`** = one `DispatchSourceTimer` on its **own serial queue**, 200 ms leeway ([Repeater.swift L23, L39-L48](https://github.com/exelban/stats/blob/v3.0.22/Kit/plugins/Repeater.swift#L23-L48)).
        - `read()` → `callback(value)` → module closure → fan-out to popup, portal, notifications, preview and every active menu-bar widget ([CPU/main.swift L197-L268](https://github.com/exelban/stats/blob/v3.0.22/Modules/CPU/main.swift#L197-L268)).
        - Same `callback` also → `SystemStats.shared.send` (cloud "Remote", no-op unless signed in) and → LevelDB write of the last value, at most every 10 × interval and 30 s per key ([reader.swift L113-L127](https://github.com/exelban/stats/blob/v3.0.22/Kit/module/reader.swift#L113-L127), [DB.swift L77-L96](https://github.com/exelban/stats/blob/v3.0.22/Kit/plugins/DB.swift#L77-L96)).
      - **Visibility gate**: readers flagged `popup`/`preview` are "locked" unless the popup or the module's Settings page is visible. Locked `start()` = one background read, no timer. Popup appear → `unlock()` + `start()`; disappear → `lock()` + `pause()` ([reader.swift L133-L177](https://github.com/exelban/stats/blob/v3.0.22/Kit/module/reader.swift#L133-L177), [module.swift L262-L311](https://github.com/exelban/stats/blob/v3.0.22/Kit/module/module.swift#L262-L311), [popup.swift L155-L169](https://github.com/exelban/stats/blob/v3.0.22/Kit/module/popup.swift#L155-L169)).
      - **Menu bar**: one `NSStatusItem` per active widget (or one per module in "oneView", or one for all in "Combined modules"). Each widget is an `NSView` drawn with `draw(_:)` inside the status button. Click = `leftMouseDown`/`rightMouseDown` action → `NotificationCenter` `.togglePopup` ([widget.swift L335-L381](https://github.com/exelban/stats/blob/v3.0.22/Kit/module/widget.swift#L335-L381)).
      - **Popup**: borderless-looking `NSWindow` (titled, full-size content, `NSVisualEffectView` `.titlebar`), positioned under the status item; app is activated (steals focus); hides on resign-key unless the user dragged it, which "locks" it open ([popup.swift L80-L131, L213-L219](https://github.com/exelban/stats/blob/v3.0.22/Kit/module/popup.swift#L80-L131), [module.swift L313-L357](https://github.com/exelban/stats/blob/v3.0.22/Kit/module/module.swift#L313-L357)).
  - **Settings storage**: `Store` = `UserDefaults.standard` with an in-memory cache dictionary ([Store.swift L14-L46](https://github.com/exelban/stats/blob/v3.0.22/Kit/plugins/Store.swift#L14-L46)); keys are strings like `CPU_updateInterval`, `RAM_combinedProcesses`. Last reader values in a vendored **LevelDB** at `~/Library/Application Support/Stats/lldb` ([DB.swift L33-L64](https://github.com/exelban/stats/blob/v3.0.22/Kit/plugins/DB.swift#L33-L64), [lldb.m L38-L74](https://github.com/exelban/stats/blob/v3.0.22/Kit/lldb/lldb.m#L38-L74)). WidgetKit data in an App Group suite ([module.swift L91](https://github.com/exelban/stats/blob/v3.0.22/Kit/module/module.swift#L91)).
  - **Login item**: `SMAppService.mainApp` on macOS 13+, legacy `SMLoginItemSetEnabled` helper otherwise ([helpers.swift L56-L84](https://github.com/exelban/stats/blob/v3.0.22/Kit/helpers.swift#L56-L84)).
  - **Hotkeys**: global + local `NSEvent` monitors for every `keyDown`/`flagsChanged` ([AppDelegate.swift L93-L99](https://github.com/exelban/stats/blob/v3.0.22/Stats/AppDelegate.swift#L93-L99), [Stats/helpers.swift L364-L383](https://github.com/exelban/stats/blob/v3.0.22/Stats/helpers.swift#L364-L383)).
- **SMC root helper** (`eu.exelban.Stats.SMC.Helper`, LaunchDaemon) — used **only for fan writes**; all SMC reads happen in the app, unprivileged.
  - Registered with `SMAppService.daemon(plistName:)` (admin approval in Login Items), legacy `SMJobBless` + `AuthorizationCreate` fallback ([helpers.swift L1122-L1150, L1224-L1290](https://github.com/exelban/stats/blob/v3.0.22/Kit/helpers.swift#L1224-L1290); [plist](https://github.com/exelban/stats/blob/v3.0.22/SMC/Helper/eu.exelban.Stats.SMC.Helper.plist)).
  - XPC interface: `version`, `setSMCPath`, `setFanMode`, `setFanSpeed`, `resetFanControl`, `uninstall` ([protocol.swift L14-L23](https://github.com/exelban/stats/blob/v3.0.22/SMC/Helper/protocol.swift#L14-L23)).
  - Client check: audit token (read via private KVC `auditToken`) → compare the client's signing certificate chain with its own ([Helper/main.swift L83-L110, L264-L366](https://github.com/exelban/stats/blob/v3.0.22/SMC/Helper/main.swift#L83-L110)). Writes run the app-bundled `smc` CLI as root after a signature check of that binary ([Helper/main.swift L149-L166, L208-L243](https://github.com/exelban/stats/blob/v3.0.22/SMC/Helper/main.swift#L208-L243)). The helper exits when its last connection closes (1 s poll, [L76-L80](https://github.com/exelban/stats/blob/v3.0.22/SMC/Helper/main.swift#L76-L80)).
- **Updater** (custom, not Sparkle): asks `api.mac-stats.com/release/latest?macOS=<version>`, falls back to the GitHub API, downloads the DMG, `hdiutil attach`, checks the app's team ID with `SecStaticCodeCheckValidity`, then runs the bundled `updater.sh`, elevated through the deprecated `AuthorizationExecuteWithPrivileges` (found by `dlsym`) when `/Applications` is not writable ([Updater.swift L64-L114, L169-L270, L280-L361](https://github.com/exelban/stats/blob/v3.0.22/Kit/plugins/Updater.swift#L280-L361), [updater.sh](https://github.com/exelban/stats/blob/v3.0.22/Kit/scripts/updater.sh)). Scheduling with `NSBackgroundActivityScheduler`; default mode "silent" = check at launch and auto-install ([Stats/helpers.swift L135-L159, L178-L205](https://github.com/exelban/stats/blob/v3.0.22/Stats/helpers.swift#L178-L205)).
- **Cloud "Remote"** (`SystemStats.swift`, 1,505 lines): OAuth + MQTT-over-WebSocket to `system-stats.com`; off unless the user signs in ([SystemStats.swift L28-L80, L215-L218](https://github.com/exelban/stats/blob/v3.0.22/Kit/plugins/SystemStats.swift#L215-L218)).
- **Device info at launch** (`SystemKit.shared`): spawns `system_profiler SPMemoryDataType`, `SPDisplaysDataType`, and `diskutil list/info` (several) synchronously on first use ([SystemKit.swift L229-L267, L476, L564-L634, L663](https://github.com/exelban/stats/blob/v3.0.22/Kit/plugins/SystemKit.swift#L229-L267)). [src]

### Rendering

- **AppKit only** for the menu bar, popups and Settings. SwiftUI appears only in the WidgetKit extension (`Widgets/`, `Modules/*/widget.swift`). [src]
- Menu-bar widgets: custom `draw(_:)` with `NSAttributedString.draw`; redraw is requested only when the stored raw value changes (`setValue` compares `Double`, so CPU and network redraw almost every tick) ([Mini.swift L92-L160](https://github.com/exelban/stats/blob/v3.0.22/Kit/Widgets/Mini.swift#L92-L160)). Each widget type creates **two** instances (preview + live) and renders the preview to PDF for an icon, at launch ([widget.swift L32-L132](https://github.com/exelban/stats/blob/v3.0.22/Kit/module/widget.swift#L32-L132)). [src]
- Popups: manual `NSRect` frames plus a few constraints; data arrives through `PopupCache.apply`, which renders only if the window is visible (or never rendered) ([popup.swift L14-L31, L69-L73](https://github.com/exelban/stats/blob/v3.0.22/Kit/module/popup.swift#L14-L73)). Charts gate `needsDisplay` on `window.isVisible` ([Charts.swift L183-L231](https://github.com/exelban/stats/blob/v3.0.22/Kit/plugins/Charts.swift#L183-L231)). Visible popups call `display()` (synchronous draw) several times per tick ([CPU/popup.swift L396-L436](https://github.com/exelban/stats/blob/v3.0.22/Modules/CPU/popup.swift#L396-L436)). [src]
- Redraw frequency = reader interval (1 s default for CPU, RAM, Disk, Network; 5 s Battery). [src]

Design implications [inf]:
1. Use one panel for all three questions (RAM, CPU, disk by app), at least 360–420 pt wide, with 13 pt body text, 11 pt minimum, `labelColor` for names and monospaced digits for numbers.
2. Lay out with Auto Layout or SwiftUI stacks, not fixed frames, so larger text and long names work.
3. Use a non-activating `NSPanel`, so the panel does not steal focus. Offer click, optional hover-to-peek with a delay, and a visible "Pin as side panel" control.
4. Keep the status item one fixed-width item with monospaced digits. Redraw it only when its text changes.
