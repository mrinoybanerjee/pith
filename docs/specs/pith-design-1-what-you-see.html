01 · THE MENU BAR

A dot that only speaks up when needed

No numbers fighting for space. The dot is a quiet outline while everything is fine and fills with color only when memory or CPU gets tight.

05 · THE RULES THAT KEEP IT PRISTINE

Design rules for every screen

13 pt
Smallest text for anything you need to read. Apple's default size; Stats uses 11.
1 accent
Amber or red only for "tight" or "critical". Everything else is native greys and materials.
CPU = whole Mac
An app's CPU is a share of the entire chip, so it never reads "340%" the way Activity Monitor can.
No jumpy lists
Rows move only when the order really changes, and ease into place. Respects Reduce Motion.
Native
macOS materials, SF fonts, real app icons, light and dark, keyboard and VoiceOver support.
Unknown ≠ 0
If macOS won't give a number, Pith says "not available", never a fake zero.
3 settings
Launch at login, refresh speed, when the dot turns amber. Nothing else to configure.
Never quits macOS
System processes can't be quit from Pith. Apps quit normally, after you confirm.

Does this look right?

  • A calm dot, a status sentence, three tiles, and the top apps with Memory / CPU / Disk tabs.
  • Click a row to explain it and quit safely; "macOS system" loads its details only when opened.
  • Pin to keep it beside your work.
