Pith · design sections 2–4 · how it works

Do almost nothing while closed.
Be exact the moment you look.

Pith reads your Mac from inside its own process, with no helper tools running every second. It works at two speeds and keeps every number honest. Nothing ships unless it passes a speed budget and an accuracy check.

02 · ARCHITECTURE

One small app, one clear path

A clock wakes the readers. Their raw numbers become one frozen snapshot. Simple rules turn the snapshot into a status sentence and a dot, and the UI only draws snapshots. No background helper, no extension, no database, no third-party packages.

NO POLLING TOOLS

Read in-process

Apple's proc_pid_rusage costs about 0.5 µs per process. Stats launches ps, top or nettop every second while a popup is open, and asks the network daemon dozens of times a second even when closed.

EVENTS, NOT TIMERS

Pressure is pushed

macOS tells Pith when memory pressure changes, so there is nothing to poll. Free space is checked once a minute.

EXACT UNITS

Matches Activity Monitor

Memory uses the "physical footprint", the same number as Activity Monitor's Memory column. CPU time is converted from Apple Silicon ticks correctly.

NO GHOST ROWS

Safe against reused IDs

Each process is keyed by its ID plus its start time, so a new process never inherits an old one's name.

FAIL VISIBLY

"Not available", never 0

Every reading is either a value or a reason it's missing. Debug builds assert on impossible numbers, such as apps adding up to more than the total.

SWIFT 6

One thread for work, one for UI

Readers run off the main thread. The UI gets one immutable snapshot per tick, so it can't race and never redraws while hidden.

02b · CODE LAYOUT

Small enough to hold in your head

The repo follows the same pattern as Vani, which already builds on your Macs: a Swift package with a core library, an app target and shell scripts. It needs only the Command Line Tools, not Xcode. The target is under 5,000 lines of Swift.

03 · SPEED BUDGET

Two speeds

Most of the day, the panel is closed. Pith then reads only what the dot needs. The full per-app sweep runs only while you are looking.

PANEL CLOSED (OR PINNED BUT COVERED)
Every 5 s
  • System totals only: memory, pressure, CPU, free space
  • No per-process work, no tools launched
  • Timer slack lets macOS batch Pith's wakeups with others
  • Stops completely while the Mac sleeps or is locked
PANEL OPEN OR PINNED AND VISIBLE
Every 1 s
  • Full sweep: every one of your processes, grouped into apps
  • Opens instantly with the last snapshot, then refreshes
  • Rows ease into place; nothing animates while hidden
  • Slower on Low Power Mode or when the Mac runs hot

NO METAL FOR CHARTS

SwiftUI's Canvas can pull in a ~93 MB renderer (a vendor claim). Pith draws its bars with plain shapes.

NO WIDGETS

Stats' widget extension once pushed Notification Center to 30–50% CPU. Pith ships none.

REUSE, DON'T ALLOCATE

Buffers are reused each tick; strings are formatted only for visible rows.

WHERE IT LIVES

Mac mini

The canonical checkout is ~/Codex/Projects/Pith on the mini, like Vani. The mini builds; install.sh copies the app to all three Macs over SSH.

SIGNING

Stable, free identity

A local "Pith Local Development" certificate, like Vani's, so macOS keeps trusting each new build. No $99 Apple account. Pith needs no special permissions.

One decision for you: where CI runs Blacksmith works only for GitHub organizations, not personal repos (Blacksmith docs). Pith will live on your personal account.
  1. Recommended: a local gate (scripts/ci-local.sh on the mini before every push), plus GitHub's own macOS runner. GitHub's runner is free for public repos, and Vani already uses it.
  2. Local gate only, with no GitHub CI.

Does this look right?

  • Architecture: in-process readers, one snapshot per tick, rules, then UI. No helpers, extensions or dependencies.
  • Speed: 5 s when closed with system totals only, 1 s when open with the full sweep. The budget table is the release gate.
  • Testing: six checks, from unit tests to council review; $0 release from the mini to all three Macs.
